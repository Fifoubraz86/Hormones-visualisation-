# Inventaire des illustrations réutilisables

Inventaire automatique (par nom de fichier) des icônes de [Bioicons](https://bioicons.com) utiles pour l'atlas et pour de futurs atlas (cardiologie, pneumologie, néphrologie, gastro-entérologie, neurologie…). Les dossiers CC BY-SA ont été exclus : ils imposeraient la même licence à l'atlas. Chemins relatifs au dossier `static/icons/` du dépôt `duerrsimon/bioicons`. Le classement par mot-clé est approximatif : regarder chaque icône avant de l'utiliser.

Licences : **CC0** sans condition ; **CC BY 3.0 / 4.0** citer l'auteur (Servier Medical Art, DBCLS/TogoTV…) ; **MIT / BSD** garder la mention de copyright.
